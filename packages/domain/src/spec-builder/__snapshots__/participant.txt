## 6. Submitting results

Submit structured results with the AI Office CLI at its absolute path (do not rely on `PATH`). Pass the JSON payload on standard input through a quoted heredoc exactly as shown; do not write payload files into the worktree.

```sh
node '/opt/ai-office/apps/cli/dist/main.js' submit <kind> --home '/Users/dev/aio home' --seat-token 'aio_seat_Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9Zx9' - <<'AIO_JSON'
<payload JSON>
AIO_JSON
```

- The seat token identifies this attempt. Use it only in this command; never write it into files, commits, issues, pull requests or messages.
- Exit 0: accepted; stdout is `{"status":"accepted","submissionId":…}`.
- Exit 2: schema error; stdout is `{"issues":[{"path":…,"code":…,"message":…}]}`. Fix every listed issue and submit again.
- Exit 3: identity or state error (for example the gate is already open or this kind is not allowed now), or the backend failed to process the submission (`submission_failed` with a `requestId`). Unless a note below says otherwise, do not retry the same submission; quote the error in your `worker_done` report.
- Exit 4: the AI Office backend is unreachable. Wait 30 seconds and run the same command again, at most 10 times (about 5 minutes).
- Submitting the same kind again before the stage gate opens replaces your earlier submission.
- `round` must equal the round number in AI Office's message; resubmitting for the same round replaces your earlier statement.
- Set `readyToConclude` to true only when you have nothing new to add. When every participant is ready, the meeting ends early.

Example `statement` payload:

```json
{
  "round": 1,
  "position": "Keep the setting client-side.",
  "arguments": [
    "No backend change is needed"
  ],
  "concerns": [
    "Sync across devices is out of scope"
  ],
  "readyToConclude": false
}
```

## 7. Questions

If you cannot state a position without an answer, use the `ask` command from your Orca preamble; AI Office routes it to the facilitator. Otherwise record open points under `concerns`.
Orca may at once post an automatic notice telling you to decide it yourself (for example "Your coordinator stopped without answering your question … Decide it yourself …"). That notice is not an answer. AI Office answers you itself, in a reply whose first line starts with `aio:`; wait for that reply.
While you wait, you may continue parts of your task that do not depend on the answer, but do not finalize anything that does.
Set no deadline of your own and never decide the question yourself: if no answer comes in time, AI Office follows its question timeout (a reminder, then escalation to a human) and replies once it has the answer.

## 8. Completion protocol

1. Now: read the requirement and the repository to prepare. Do not submit anything yet; report `worker_done` to say you are ready.
2. Each round arrives as a message from AI Office with the round number, the topics and every statement of the previous round. Submit your `statement` for that round, then report `worker_done`.

- Completion protocol: submit first, then report `worker_done`. Never report `worker_done` for a turn before its submission has been accepted (exit 0).
- Do not exit after `worker_done`: AI Office keeps this agent open between turns and stops it itself.
- Each turn has 15 minutes; the whole meeting has 60 minutes.
- If AI Office does not receive a required submission in time it sends one reminder and then waits 5 minutes before escalating the stage to a human.
