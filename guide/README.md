# User guide

1. [Install](install.md): build AI Office from source and set up the
   `ai-office` command.
2. [Prerequisites](prerequisites.md): Orca, Claude Code, Codex, `gh`, and the
   GitHub account and repository settings production mode expects.
3. [Configuration](configuration.md): the data directory, every `config.toml`
   key, and workflow templates.
4. [Usage](usage.md): starting and stopping, registering a repository, running a
   workflow through its gates, cleanup, cancel and replay.
5. [Safety](safety.md): where decisions happen, what agents can and cannot do,
   the accepted residual risks, and what data is kept.
6. [Troubleshooting](troubleshooting.md): every startup refusal and the common
   runtime problems.
7. [Development](development.md): working on AI Office itself.

Dogfooding (developing AI Office with AI Office) has its own runbook,
`dogfooding.md`, added separately.
