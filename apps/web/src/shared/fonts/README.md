# Bundled font

`ai-office-pixel.woff2` is the ASCII subset (U+0020–007E) of
[DotGothic16](https://github.com/google/fonts/tree/main/ofl/dotgothic16),
Copyright 2020 The DotGothic16 Project Authors. It is licensed under the
[SIL Open Font License 1.1](./OFL.txt), retrieved 2026-11-18.
The source license declares no Reserved Font Names; the modified font is
nevertheless renamed **AI Office Pixel** to distinguish this subset.
Chinese UI text uses system fonts. No runtime CDN requests are made.

Generated with fontTools subset and Brotli: retain U+0020–007E, set name IDs
1, 4, 16 to `AI Office Pixel`, ID 6 to `AIOfficePixel-Regular`, and save WOFF2.
Source: `https://raw.githubusercontent.com/google/fonts/main/ofl/dotgothic16/DotGothic16-Regular.ttf`.

UI colors follow the Endesga 32 palette by Endesga, plus the designated
`#F2F4F8` UI background. Icons are original geometric drawings.
